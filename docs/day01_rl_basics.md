## Topic

Introduction to Reinforcement Learning

## What I Learned

I studied the basic structure of reinforcement learning. Reinforcement learning is a learning method where an agent interacts with an environment, takes actions, receives rewards, and improves its decision-making over time.

## Key Concepts

- Agent
- Environment
- State
- Action
- Reward
- Episode
- Policy
- Value
- Q-value
- Exploration
- Exploitation

## Key Takeaway

Reinforcement learning is different from supervised learning because the agent learns through interaction and feedback, not from fixed labeled answers.
